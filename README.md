# Farmand Bazdiditehrani — Personal Portfolio

Portfolio site hosted at [farmand-bt.github.io](https://farmand-bt.github.io).  
Built with pure HTML, CSS, and minimal vanilla JavaScript — no frameworks, no build step.

## Local preview

Open `index.html` directly in any browser (double-click or drag into the address bar):

```
file:///C:/path/to/farmand-bt.github.io/index.html
```

Or use any static file server:

```bash
npx serve .
# or
python -m http.server 8080
```

## Deploy

Push to the `main` branch — GitHub Pages auto-deploys from the repo root.

## Customising content

All content lives in `index.html`. Each section is commented with what to edit.  
Skill chips and project tags are plain `<span>` elements — add, remove, or rename them directly in the HTML.

To update the CV: replace `assets/cv.pdf` with your actual CV file and remove the placeholder note from the Contact section.
